# Vikas Marothia Portfolio

Professional portfolio website built with Flask for a backend software engineer profile.

## Features
- Resume download
- Experience and project sections
- Contact form
- Admin dashboard for messages
- Responsive design

## Run locally
```powershell
cd /d "e:\Python Workspace"
"e:/Python Workspace/.venv/Scripts/python.exe" "e:/Python Workspace/app.py"
```

## Deployment
This project is ready to be deployed on services like Render, Railway, or PythonAnywhere.
